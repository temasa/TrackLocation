# Change Requests

Change requests capture product changes that may affect existing behavior, screens, data model, source code, migrations, or tests.

## Required CR sections

Each CR should include:

- Status
- Problem
- Decision
- Impact Matrix
- User-facing changes
- Behavior changes
- Navigation impact
- UI impact
- Data model impact
- Source-code impact
- Migration impact
- Test impact
- Open questions
