# Glossary

## Always-recording

A foreground location recording mode that appends location points to the canonical location log until the user turns it OFF.

## Session

An ON-to-OFF always-recorded location range. A session is not a trip.

## Trip

A user-declared travel range over the canonical location log. A trip starts and stops explicitly and references location rows by inclusive boundaries.

## Canonical location log

The append-only table of raw location points used by both sessions and trips.

## Observer

The Accessibility Event Observer feature area that captures accessibility events, extracts UI tree snapshots, stores searchable text, and supports local/remote inspection.

## Denylist

A configurable package list used to exclude high-noise system packages from Observer capture.

## Source Change Manifest

The implementation document that maps accepted product and architecture changes to source files that must be created, edited, deleted, migrated, or tested.
