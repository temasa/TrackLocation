# Google Stitch Transfer Prompt

Upload `list-screen-trip-light.png` and `list-screen-trip-dark.png` as visual references, then use this prompt in Google Stitch:

```text
Create a clean, modern Android mobile ListScreen for a trip-tracking app.

The app tracks a driver's current trip using location. The user taps Start when a trip begins and Stop when they arrive. Each completed trip becomes a record in the list.

Use the uploaded light and dark mockups as the main visual reference. Preserve the core structure:
- Top app header for "Trips" / "Trip Tracker".
- Current trip panel with a clear Start action.
- Dashboard metrics: number of trips, total distance, total hours.
- Search or filter row for trips, places, and dates.
- Recent trip cards with:
  - start location
  - end location
  - trip date/time
  - distance in km
  - duration
  - average speed
- Bottom navigation with Trips selected.

Design style:
- Clean and modern, not flashy.
- Feels like a trip journal plus live tracking tool.
- Light theme should feel bright, calm, and operational.
- Dark theme should feel polished, readable, and suitable for night driving.
- Use route/destination visual cues, subtle cards, clear spacing, and strong hierarchy.

Output both light and dark theme screens for a 390 x 844 mobile viewport.
```
