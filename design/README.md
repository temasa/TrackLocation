# ListScreen Trip Mockup

These files capture the trip-history ListScreen direction for implementation in Codex CLI.

- `list-screen-trip-light.svg`: light theme mobile mockup.
- `list-screen-trip-dark.svg`: dark theme mobile mockup.
- `list-screen-trip-light.png`: light theme raster reference for Google Stitch.
- `list-screen-trip-dark.png`: dark theme raster reference for Google Stitch.
- `google-stitch-prompt.md`: prompt to paste into Google Stitch with the PNG uploads.

Figma source: https://www.figma.com/design/ijmYAMdwxfol0AFq8PrUn9

Screen intent:
- Current trip action at the top.
- Dashboard metrics for trips, total distance, and total hours.
- Trip cards showing start location, end location, distance, duration, and average speed.
